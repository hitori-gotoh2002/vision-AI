exp01_nodata_mask 개선 내용
============================================================

1. 개선 목적
------------------------------------------------------------
평가 영상의 촬영 범위 밖은 완전히 검정색(0, 0, 0)으로 제공됩니다.
대회 규칙에 따라 pre 또는 post 영상 중 하나라도 검정인 화소는
판정 대상이 아닙니다.

공식 베이스라인은 이 무영상 영역을 최종 예측에서 명시적으로
제거하지 않아, 검은 경계 부근에서 증축이나 벌목 오탐지가 발생할 수
있습니다. 이 버전은 해당 영역의 예측을 배경으로 강제 변환합니다.


2. 변경한 코드
------------------------------------------------------------
추론 후 폴리곤으로 변환하기 전에 다음 마스크를 적용했습니다.

    valid = np.any(pre != 0, axis=2) & np.any(post != 0, axis=2)
    lab = lab.copy()
    lab[~valid] = 0

의미:

- pre 화소가 검정이면 무효
- post 화소가 검정이면 무효
- 두 영상이 모두 검정이 아닌 위치만 유효
- 무효 화소의 예측 클래스를 0(배경)으로 변경


3. 변경하지 않은 항목
------------------------------------------------------------

- UNet-ResNet18 모델 구조
- 6채널 pre/post RGB 입력
- 주최 측이 제공한 unet_r18_cd.pt 가중치
- ImageNet 평균/표준편차 정규화
- 증축/new_building, 벌목/tree_removal 클래스 구성
- 30px² 미만 조각 제거
- 0.5px 폴리곤 단순화
- 배치 크기 16

즉, 모델을 재학습하거나 가중치를 변경하지 않고 최종 예측의
무효 영역만 제거했습니다.
